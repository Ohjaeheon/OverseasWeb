너는 Spring Boot와 React 기반의 엔터프라이즈 환경에 능숙한 시니어 풀스택 개발자야.
현재 우리는 하드코딩된 정적 화면들을 '메타데이터 기반의 동적 렌더링 시스템'으로 마이그레이션하는 프로젝트를 진행 중이야. 첫 번째 파일럿 타겟은 /OverseasPortal/evangelism 화면이야.

[Task Overview]
기존 /OverseasPortal/evangelism 화면은 상단에 요약 데이터, 하단에 상세표가 하드코딩되어 있어. 이를 관리자가 백오피스에서 설정한 메타데이터(UI 구성, 데이터 변수 매핑, 계산식)를 바탕으로 동적 렌더링되도록 아키텍처를 변경해야 해.

[Action Required]
작업 공간에 있는 기존 /OverseasPortal/evangelism 관련 프론트엔드(React) 및 백엔드(Spring Boot) 코드를 먼저 분석한 후, 아래 3가지 스텝에 맞춰 코드를 생성 및 수정해 줘.

Step 1: DB 스키마 설계 (DDL)

동적 메뉴 구성을 위한 테이블 구조를 설계해 줘. (RDBMS 사용)

필수 테이블: dynamic_menus (메뉴 기본 정보), menu_components (상단 위젯, 하단 표 등 UI 컴포넌트 정보), menu_variables (매핑할 원천 데이터 변수), menu_formulas (사용자가 지정한 계산식).

각 테이블의 DDL과 초기 테스트용 데이터를 삽입하는 DML을 작성해 줘.

Step 2: Spring Boot 백엔드 구현

DB에 저장된 계산식 문자열(예: (varA + varB) / varC)을 안전하게 파싱하고 계산할 수 있는 로직을 구현해 줘 (Spring Expression Language - SpEL 적용 권장).

프론트엔드로 전달할 동적 메뉴 메타데이터 API의 Response DTO 구조를 설계하고 Controller, Service, Repository 기본 코드를 작성해 줘.

기존 비즈니스 로직을 동적 쿼리/변수 매핑 방식으로 전환하기 위한 인터페이스 설계를 제안해 줘.

Step 3: React 프론트엔드 구현

백엔드에서 전달받은 JSON 메타데이터를 파싱하여 화면을 그리는 DynamicPageRenderer 컴포넌트를 작성해 줘.

상단 요약 데이터를 보여줄 DynamicWidget 컴포넌트와 하단 목록을 보여줄 DynamicTable 컴포넌트의 뼈대를 만들어 줘.

/OverseasPortal/evangelism 경로로 접속 시 이 동적 렌더링 시스템이 작동하도록 라우팅 및 뷰 컴포넌트를 수정해 줘.

[Constraint]

코드는 모듈화가 잘 되어 있어야 하며, 향후 다른 메뉴(/OverseasPortal/...)를 전환할 때도 재사용할 수 있도록 확장성을 고려해 작성해 줘.

주요 비즈니스 로직(특히 수식 계산 및 변수 매핑)에는 상세한 주석을 달아 줘.
