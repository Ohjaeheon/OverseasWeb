==================================================
  해외 주간예배출결 자동 취합 프로그램 사용법
==================================================

본 프로그램은 해외 19개 지역별 비밀번호 암호화 엑셀 파일들을 메인 템플릿 파일(양식.xlsx)에 자동으로 취합 및 분배하는 도구입니다.

[사용 방법]

1. 최상위 폴더(메인 디렉토리) 구성:
   작업을 진행할 메인 폴더 안에 반드시 아래 3개의 파일이 존재해야 합니다.
   - run_merge.bat (더블클릭하여 실행하는 배치 파일)
   - merge_attendance.py (실제 취합 연산을 처리하는 파이썬 스크립트)
   - 양식.xlsx (취합본 생성의 기준이 되는 템플릿 파일)

2. 하위 폴더 자동 순회 및 감지:
   - 메인 폴더 내에 존재하는 모든 하위 폴더들을 자동으로 탐색합니다.
   - 각 하위 폴더명(예: "6월4주 주간예배출결", "7월1주 주간예배출결")에서 "6월4주"와 같은 주차 정보를 자동으로 추출하여 결과 파일 이름에 반영합니다.
   - 주차 정보가 매칭되지 않는 폴더명(예: "수요예배")의 경우, 폴더명 자체가 주차 정보로 취급됩니다.

3. 취합 실행:
   - 'run_merge.bat' 파일을 마우스 더블클릭하여 실행해 주세요.
   - 필요한 파이썬 라이브러리(openpyxl, msoffcrypto-tool)의 설치 유무를 알아서 판단하여 누락된 경우 자동 설치하고 실행합니다.
   - 작업이 완료되면 각 하위 폴더 내부에 다음 2개의 결과 파일이 생성됩니다.
     * 해외-예배출결현황(주차)_주일.xlsx
     * 해외-예배출결현황(주차)_수요.xlsx

==================================================
  ★ 필수 주의 사항 ★
==================================================

1. 비밀번호 정책 유지 (gotjsqn)
   - 이 프로그램이 취합하는 원본 엑셀 파일들과 취합 대상 템플릿(양식.xlsx)은 모두 비밀번호 'gotjsqn' (한글 키보드로 "해선부")으로 보안 설정되어 있어야 합니다.
   - 결과물 파일 또한 보안을 위해 동일한 비밀번호('gotjsqn')로 자동 재암호화되어 저장됩니다.

2. 시트(탭) 누락 시 자동 건너뛰기
   - 특정 국가의 엑셀 파일에 시트가 누락된 경우(예: '09.멕시코...' 파일에 '(수요)예배출석현황' 시트가 없는 경우), 에러가 나며 멈추지 않고 해당 국가에 대한 작업만 건너뛴 후 나머지 정상 국가들을 모두 정상 취합합니다.

3. 템플릿 수식 보호
   - '양식.xlsx' 시트 내의 참석율 및 합계 셀에는 사전에 설정된 정교한 엑셀 수식(배열 수식 등)이 들어가 있습니다.
   - 프로그램은 수식이 들어있는 셀을 절대 덮어쓰지 않고 보호하며, 사용자가 직접 수치 데이터를 입력하는 셀(C열 이후, 6행 이후 중 수식이 없는 영역)에만 원본 값을 매칭하여 데이터를 복사합니다.

4. 엑셀 파일 열림 상태 주의
   - 취합 대상 원본 엑셀 파일이나 양식 파일이 다른 엑셀 프로그램 등으로 열려있을 경우, 윈도우 파일 잠금(Lock) 기능 때문에 실행 중 권한 에러(WinError 32)가 발생할 수 있습니다.
   - 실행 전 모든 관련 엑셀 파일들을 닫아두고 배치 파일을 실행해 주세요.
